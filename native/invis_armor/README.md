# Invisible Armor (`invis_armor`)

Client-only Horizon cosmetic mod. Options → Mods → Invisible Armor → Configure armor visibility.

- **Opacity**: 0–100% slider; default **100%**. Drag, or focus with Tab and use arrow keys.
- **Hats Only**: On/Off; default **On**. Keeps helmets visible and hides other worn armor and elytra. Opacity applies to the visible equipment.

Applies to player equipment, including remote players, inventory previews and the FirstPersonModel body. Armor dyes, trims, glint and emissive layers retain their colors and fade together. Skin layers, held items, equipment stats and networking are unchanged. Disabling the mod restores normal rendering. Settings persist locally.

Package: `python3 native/tools/native.py package invis_armor`.
